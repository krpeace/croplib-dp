# 0020. 일사(Rs) 유효성 규칙과 대체 순서, ETo 연속 채움 한도 (#44, #28 S0-a)

날짜: 2026-11-08

## 배경
- 일사(`sumGsr`)가 `0.0`으로만 오는 지점 7곳(문경 273, 성산 188, 순천 174, 영주 272, 울진 130, 정선군 217, 제천 221)이 있다. 일사 값이 아예 없는 지점은 25곳이다(2026-11-07 확인, 적산일사 수집 결과 기준).
- 지금 코드는 `0.0`도 관측값으로 써서 여름 맑은 날 ETo가 5.55 → 1.92 mm/d(−65%)로 줄어든다. 계약 검사(일사 0~40, ETo 0~15)로는 걸러지지 않는다. 적산일사도 영주가 "평년의 100%"(1.0 ÷ 1.0 MJ)처럼 틀리게 나온다.
- 일사도 일조시간도 없는 날은 ETo를 앞 7일 평균으로 채우는데 한도가 없어, 며칠이든 같은 값이 이어졌다.
- 이 규칙은 전 지점으로 넓히는 이슈 #28의 사전 작업(S0)이다. 계획서: #28 댓글 D5·3절. 승인: 2026-11-07·11-08.

## 결정
1. **일 단위:** 일사가 `0.05 × Ra`(천문일사, 식21)보다 작으면 결측. `core/solar.py`가 추정 일사를 자르는 하한과 같은 값이다. 예: 영주 8/4는 하한 약 1.9 MJ라 측정 1.0은 무효다.
2. **달력 월 단위:** 한 지점의 한 달에 자료가 10일 이상이고 그중 무효가 90% 이상이면 그 달 일사 전부를 무효로 본다. 정선군 2월처럼 27일이 `0.0`이고 하루만 4.57인 달은 그 하루도 버린다. 자료가 10일 미만인 달은 일 단위 규칙만 쓴다. 달마다 따로 판단하므로 센서를 고친 다음 달부터는 다시 쓴다. "자료"는 값이 있는 날이다(빈 날은 세지 않음).
3. **대체 순서:** 유효한 일사 → 일조시간(식35, 앙스트롬 a 0.25·b 0.50, 지금 규칙) → 기온차(식50, `core/solar.py rs_s1`, kRs는 지점별) → 비움. 일조 없이 기온차를 쓸 때도 `0.05×Ra ~ Rso`로 자른다.
4. **kRs는 지점별 값을 받는다:** `StationMeta.krs`, 기본 0.16(내륙). 해안 0.19와 해안 목록 연결은 S0-b(#48). **예보용 일사 기본값(`io/coefficients.py:31`)은 건드리지 않는다.** 바꾸면 이미 도는 대표 9곳의 예보 값이 달라지므로 별도 승인이 필요하다.
5. **연속 채움 한도 7일:** 앞 7일 평균으로 채운 날이 연속 7일을 넘으면 8일째부터 ETo를 비운다(`eto_mm = None`, `filled = true`). 정상 ETo가 나온 날이 끼면 세기를 다시 시작한다. 빠진 날짜(행 자체가 없는 날)도 같은 한도다. 앞에 값이 없는 첫날은 지금처럼 `0.0`으로 채우고(기존 시험 `test_first_day_without_eto_is_zero`), 그날부터 세기 시작한다.
6. **적산일사(`sun_daily`)는 관측 일사만 쓴다.** 걸러진 날은 비우고(평년 값으로 채워 `filled`), 일조시간·기온차 추정값은 섞지 않는다. 일사 값은 있었는데 모두 걸러져 평년선이 비는 지점(일사가 늘 `0.0`)은 줄이 안 만들어져 DB의 옛 줄이 남으므로, **삭제 없이** 같은 키로 `rs_*` 열을 비운 줄(`filled = true`)을 올려 덮어쓴다. 일사 칸이 한 번도 없던 지점은 지금처럼 줄을 만들지 않는다.
7. **`rs_source`:** 계산 결과(`daily_weather`의 각 줄)에 `observed` / `sunshine` / `temp_range` / `None`을 담는다. DB 열이 없어 올리지 않는다(`WEATHER_COLS` 그대로). 칸 추가는 CropMon에 요청(C7, 계약 v1.7 후보, S2 전)한다.

## 알아 둘 것
- `weather_daily.rs_mj`에는 이제 기온차 추정값이 들어갈 수 있다(예전에는 일사도 일조도 없으면 비었다). 어느 방식인지는 `rs_source`가 DB에 올라가기 전까지 DB에서 알 수 없다.
- 월 단위 규칙은 한 번에 받은 자료 범위 안에서 판단한다. 물 수집기는 작기 시작(또는 3/1)부터 어제까지만 받으므로, 범위 끝의 10일 미만인 달은 일 단위 규칙만 적용된다.
- 올해 일사가 전부 무효인데 평년선은 있는 지점은 지금처럼 평년 값으로 채워(`filled = true`) 누적이 평년과 같게 나온다. 값이 비는 것이 아니라 "채운 값"으로 표시된다. 바꾸려면 별도 결정이 필요하다.
- ETo가 비었을 때의 물 상태 판정 보류는 S2에서 한다. `water_balance`는 ETo가 비면 `eto_src='없음'`, ETc 0으로 계산하므로, S2 전에는 대표 10곳의 연속 결측이 7일을 넘는 드문 경우에만 나타난다.
- DB 구조·`CALC_VERSION`·계약 버전은 바뀌지 않는다.
