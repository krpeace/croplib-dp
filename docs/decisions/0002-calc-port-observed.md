# 0002. cropwater 관측 계산 옮기기 (물1-1)

날짜: 2026-10-24

## 결정
- **원본은 cropwater `feat/cycle02-forecast` 브랜치**다. 현장 PC가 H3 시험에 쓰는 코드라서, 서버 결과를 춘천(101)에서 PC 결과와 비교할 기준이 된다. 기본 계산(`fao56_core.py`)은 main과 숫자가 같다. 브랜치는 읽기만 했다.
- **물1을 셋으로 나눈다.** 물1-1 관측 계산(이번), 물1-2 예보 계산(시각별 → 하루 값, 일사 추정, 3일 전망 세 경로), 물1-3 수집기(ASOS·단기예보 조회와 연결).
- **옮긴 것:** FAO-56 식(`core/fao56.py`), ASOS 하루 값 → ETo(`core/daily_weather.py`), 관측 물수지와 상태 판정(`core/water_balance.py`). 식은 그대로 두고 pandas 없이 날짜순 목록으로 계산한다.
- **옮기지 않은 것:** 엑셀 만들기, CSV 읽기(관수 기록, 작물 라이브러리, 지점 백업), 증발접시 계수. 서버는 DB 값을 쓰고 엑셀은 11월(물6)에 따로 정한다. 관수 자동 규칙(`auto_irrigate`)은 검증용이라 뺐다.
- **상태는 계약 v1 코드로 낸다** (`need`, `caution`, `normal`, `wet`, `dormant`). 판정 순서와 기준(주의 = RAW × 0.5, 과습 = 끝 Dr 0.05 mm 미만, 과습은 관측 날만)은 cropwater `soil_status`와 같다. 자료가 없으면 상태도 없음(None)이다.
- **토성 값은 코드에 넣지 않는다.** TAW·RAW는 입력(`Soil`)으로 받는다. 서비스는 DB `scenarios`의 값(양토 0.25/0.12)을, cropwater 대조 테스트는 cropwater 값(0.22/0.10)을 쓴다.
- **관측이 빠진 날:** ETo를 구하지 못한 날과 ASOS 행이 없는 날은 앞 7일 ETo 평균으로 채우고 `filled`로 표시한다. 행이 없는 날의 강수는 비워 두고(물수지에서는 0), 행이 있는데 일강수 칸이 빈 날은 ASOS 관례대로 0이다. 그날 아침 예보(D+0)로 채우는 운영 규칙은 물1-2에서 더한다.
- **채운 날의 `eto_src`는 "없음"**으로 둔다. 관측도 예보도 아닌 평균값이라서다. 물1-2 뒤에는 예보로 채운 날이 "예보"가 된다.
- **계산 버전은 패키지 버전을 그대로 쓴다** (`core.CALC_VERSION`, 지금 0.1.0). 식이나 판정 기준을 바꾸면 버전을 올린다.

## 같은 숫자인지 확인한 방법
- cropwater `tests/test_fao56.py`의 계산 테스트를 그대로 옮겨 통과시켰다.
- **대조 테스트**(`tests/test_cropwater_parity.py`): 가짜 입력을 cropwater 코드에 넣어 받은 숫자(`tests/data/cropwater_golden.json`)와 비교한다.
  - 30일 ASOS 자료(일사 없음, 증기압 없음, 행 없음, 기온 없음, 큰 비 포함) → ETo, 채운 ETo, Kc 1 물수지
  - 사과 시나리오 3(기후보정) Kc 곡선 + 관수 1회 + 226일 물수지 → Kc, ETc, Dr, Ks, DP, 상태 다섯 가지 모두
  - 차이는 cropwater가 반올림해 낸 자리 안이거나 10⁻⁹ 이하였다.
- 기준값을 다시 만들려면: cropwater 브랜치를 내려받은 폴더를 인자로 `python -I tests/data/make_cropwater_golden.py <폴더>`.

## 남은 것 (확인 필요)

> 2026-10-24 해결: CropMon 데이터 계약 v1.1(PR #10)이 재배 방식별 Kc 표를 더하고 사과 기본을 시나리오 3으로 바꿨다. 기후보정은 결정 0003에서 `core/kc.py`로 옮겼다.

- **사과 Kc 값이 cropwater 현장 PC와 다르다.** DB 사전(`crops`)은 FAO-56 Table 12 시나리오 1(0.45 / 0.95 / 0.70, 청경·서리)이고, 현장 PC 설정은 시나리오 3(0.50 / 1.20 / 0.95, 초생재배·서리, "한국 사과원 일반")에 기후보정을 한다. 춘천 비교와 11/06 공개 전에 어느 값을 쓸지 정해야 한다. 바꾸려면 CropMon 사전 자료를 고친다(이 저장소는 DB 구조·사전을 고치지 않는다).
