# 0015. 전망 요약(`status_start`)의 휴면기는 회차 발표 날짜로 판정

날짜: 2026-10-28 (이슈 #26, CropMon#37)

## 배경
- 종합 화면의 "오늘" 칸은 `water_outlook_summary.status_start`를 읽는다.
- 아침(02시) 회차는 전날 관측 물수지 끝 값에서 출발하므로 `start_date`가 전날이다.
- 사과 작기 마지막 날은 10/27(`season_end`)인데, 10/28 02시 회차에서 출발 날짜(10/27)의 Kc > 0으로 판정해 작기가 끝난 다음 날 아침에도 "관수 필요"·"주의"·"보통"이 나왔다 (같은 줄의 앞으로 3일 10/29~31은 휴면기).
- 반대로 작기 첫날(4/1) 아침 회차는 출발 날짜가 3/31(Kc = 0)이라 첫날 아침에 "휴면기"로 나오는 하루 어긋남이 생긴다. 저녁 회차는 출발 날짜가 그날이라 어긋나지 않는다.

## 왜 휴면기만 발표 날짜 기준이고 부족한 물(Dr)은 출발 날짜 그대로인가
- **부족한 물(`dr_start_mm`)은 출발 날짜 끝 값 = 오늘 아침 흙 상태가 맞다:** 전날 밤(관측 물수지 끝)까지 빠져나간 물의 양이 곧 오늘 아침 뿌리 근처에 부족한 물이기 때문이다. 저녁 회차도 그날 아침 예보로 오늘 하루를 진행한 끝 값을 쓰므로 바꾸지 않는다.
- **휴면기(`dormant`)는 "오늘 작기가 진행 중인가"를 묻는 상태다:** 어제까지 작기였더라도 오늘(회차 발표 날짜) 작기가 끝났으면 오늘 관수를 권하면 안 되고, 반대로 어제까지 휴면기였더라도 오늘 작기가 시작됐으면 오늘 아침 상태를 보여 주어야 한다.
- **과습(`wet`)은 출발 날짜가 작기 안(`kc_start > 0`)이고 관측 물수지 날일 때만 판정한다:** 작기 첫날(4/1) 아침 회차는 출발 날짜(3/31)가 작기 밖이라 포장용수량(Dr = 0)에서 출발하는데, 비가 와서 젖은 것이 아니므로 과습으로 판정하면 안 된다(`normal`).

## 결정
`core/outlook.py`의 `outlook_summary(ol, raw, kc_start, kc_today)`에서 `status_start`를 아래 순서로 정한다.

| 순서 | 조건 | 결과 |
|---|---|---|
| 1 | 회차 발표 날짜(한국 날짜)의 Kc(`kc_today`) ≤ 0 | `dormant` |
| 2 | 관측 물수지 날(`pre` 없음)이고 출발 날짜의 Kc(`kc_start`) > 0이고 Dr < 0.05 mm | `wet` |
| 3 | Dr ≥ RAW | `need` |
| 4 | Dr ≥ RAW × 0.5 | `caution` |
| 5 | 그 밖 | `normal` |

- `collectors/water.py`는 `crop.kc(D.date())`(회차 발표 날짜, 한국 날짜)를 `kc_today`로 넘긴다.
- `dr_start_mm`, `start_date`, 전망(`water_outlook`)·관측(`water_balance_daily`)의 날마다 판정, DB 테이블 구조는 바꾸지 않는다.
- 판정 규칙이 바뀌었으므로 `CALC_VERSION`(패키지 버전)을 `0.1.0` → `0.1.1`로 올린다.
