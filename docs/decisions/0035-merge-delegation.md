# 0035. 병합 위임: croplib-dp 채팅이 조건부로 병합한다 (0034 이후 운영 규칙)

날짜: 2026-11-12

## 왜 바꿨나
사용자가 11/13~11/14 출장으로 병합을 할 수 없다. 이 기간에도 검토가 끝난 작은 PR이 병합 대기로 쌓이지 않게 하려고, 사용자가 croplib-dp 채팅(Claude)에 병합을 위임했다.

## 결정
1. 병합은 계속 사용자 몫이다. 작업 창(Antigravity 세션)은 PR을 열고 자동 검사 통과까지만 한다.
2. 예외로 croplib-dp 채팅은 아래 조건을 **모두** 갖춘 PR만 병합할 수 있다.
   - 자동 검사(ruff, pytest) 통과
   - 커밋 목록, 바뀐 파일, 지운 시험 줄을 직접 확인(기존 시험을 고쳤다면 이유가 PR에 있음)
   - 이슈와 무관한 커밋 없음
   - 워크플로, Actions 변수, DB 구조(마이그레이션), 삭제 작업, 스위치(`NONREP_SCENARIOS` 등) 켜기와 무관
3. 조건 하나라도 걸리면 병합하지 않고 사용자에게 남긴다.
4. 이슈 닫기는 계속 사용자가 한다. DB를 바꾸는 SQL은 계속 사용자가 SQL Editor에서 실행한다.
5. 병합한 PR은 채팅이 이슈나 PR에 병합 사실과 검토 요약을 댓글로 남긴다.

## 한계
- 채팅은 사용자가 메시지를 보내거나 예약된 점검 시각이 올 때만 움직인다. 상시 감시가 아니다.
- 이 위임은 croplib-dp 저장소만 해당한다. CropMon 저장소는 CropMon 채팅이 맡고 별도로 정한다.
