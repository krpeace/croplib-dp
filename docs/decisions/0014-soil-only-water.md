# 0014. 작물 공통(흙만 본 물 상태) 계산과 판정 (`soil_water_daily`, 계약 v1.5)

날짜: 2026-10-28 (이슈 #24, CropMon#35·결정 0020)

## 배경
- 작물을 고르지 않고 토성(12종)만 반영한 흙 물 상태를 보여 주기 위해 데이터 계약 v1.5에서 `soil_water_daily` 표와 추정 토성 3종(`sandy_clay_loam`, `clay_loam`, `sandy_clay`), 작물 공통(`crops.common`)을 더했다.
- "기준작물(잔디)"이라는 이름은 지도사가 내 작물 대신 쓰는 오해가 생기므로 쓰지 않고, **"작물 공통"**으로 부르며 관수 지시 대신 흙에 남은 물 비율(`aw_pct`)과 6가지 상태를 보여 준다.

## 결정

### 1. 고정 조건과 3/1 재시작
- 물수지 식은 기존 `core.water_balance.observed_water_balance(crop=None, ...)`을 그대로 쓴다 (`crop=None`이면 Kc = 1.0, cropwater `cropwater_multi`와 같은 숫자).
- 흙 조건: `Soil.from_soil(fc, wp, zr_m=0.5, p=0.40, dr0_mm=0.0)` — 겉흙 깊이 50 cm, 고갈 허용 분율 p = 0.40, 지표유출·모관상승 0. `fc`·`wp`는 DB `soil_types`의 계산값(추정 3종 포함 12종 모두 같은 방법)을 쓴다.
- **해마다 3/1에 Dr = 0(포장용수량)으로 새로 시작**해서 11/30까지 계산한다. 겨울(12~2월)은 언 땅·낮은 증발에서 일별 고갈량 숫자가 의미 없으므로 물수지를 진행하지 않고 `status = 'winter'`, `dr_mm`·`aw_pct`·`dp_mm`·`days_to_dry`는 빈 칸으로 둔다(`eto_mm`·`rain_mm`·7일 합은 있으면 채움).
- 결측일은 기존 관측 물수지와 같은 규칙(앞 7일 평균, `filled`)을 따른다.

### 2. 상태 판정 경계와 근거 (`core/soil_water.py`)
작물용 `soil_status`(`need`, `caution`, `normal`, `wet`, `dormant`)와 섞지 않고 별도 순수 함수로 둔다. 위에서부터 처음 맞는 것으로 판정한다.

| 코드 | 화면 이름 | 조건 | 근거 |
|---|---|---|---|
| `winter` | 겨울철 | 12~2월 | 겨울철 판정 유예, 3/1 Dr = 0 재시작 |
| `pool` | 물 고임 | 그날 끝 Dr < 0.05 mm 이고, 그날 또는 전날 DP ≥ 1 mm | 포장용수량을 넘어 심층침투가 발생한 직후(이틀까지) |
| `ample` | 충분 | `aw_pct` ≥ 80 | 포장용수량 부근 충분 구간 구분용 |
| `fair` | 보통 | 60 ≤ `aw_pct` < 80 | **60% = RAW 경계** (p = 0.40 이므로 RAW = 0.40 × TAW, 남은 물 60%까지 스트레스 없음, Ks = 1.0) |
| `dry` | 건조 | 30 ≤ `aw_pct` < 60 | **30% = Ks = 0.5 지점** (남은 물이 TAW − RAW = 60%의 절반인 30%일 때 FAO-56 식(84) 수분 스트레스 계수 Ks = 0.5로 증발산이 절반으로 줄어듦) |
| `very_dry` | 매우 건조 | `aw_pct` < 30 | Ks < 0.5 심한 수분 부족 구간 |

- `aw_pct` = (TAW − Dr) ÷ TAW × 100.
- `days_to_dry`: `fair`일 때만 ⌈(RAW − Dr) ÷ (그날까지 7일 평균 ETo)⌉. 평균 ETo가 0이면 빈 칸.
- `eto_7d_mm`, `rain_7d_mm`: 그날까지 7일 합(자료 있는 날만 합, 7일 모두 없으면 빈 칸).

### 3. 적산온도 (작물 공통)
- 기준온도 **5℃**, 단계 1,000·2,000 ℃·일. `crops` 사전의 `common` 행(`t_base_c = 5`)을 읽어 기존 `collectors/heat_sun.py`가 대표 10곳의 평년·올해 적산온도를 `heat_daily`에 `crop_id = 'common'`으로 올린다.

### 4. 수집·올리기 범위 및 소급 결과
- 대상 지점: `stations.has_forecast`인 대표 10곳(`101`, `216`, `119`, `131`, `129`, `146`, `156`, `136`, `192`, `189`).
- 매 회차 3/1부터 계산하되, 평소 회차는 최근 14일만 `soil_water_daily`에 덮어쓰고(`SOIL_UPLOAD_DAYS = 14`), 초기 소급이나 전체 갱신은 `--soil-backfill` 옵션으로 그해 1/1부터 전체를 올린다.
- 2026-10-28 소급 실행 결과 (2026-01-01 ~ 2026-10-27, 300일 × 10지점 × 12토성 = 36,000줄, `heat_daily` `common` 3,650줄):
