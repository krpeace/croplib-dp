# 0008. 3일 전망 요약과 관수 필요 예상일 (계약 v1.3)

날짜: 2026-10-25

## 결정
- **요약 한 줄을 계산해 올린다** (`core/outlook.outlook_summary` → `water_outlook_summary`). 서비스 엑셀 "관수 전망" 시트 위쪽과 같다: 출발 날짜·부족한 물·상태, 관수 필요 예상일(중심·빠르면·늦으면), 권장 관수량(순·공급), 주 지표 3일의 ETc 합 ± 오차, 강수 합, 기대 강수 합.
- **관수 필요 예상일은 주 지표 3일만 본다** (2026-10-25 사용자 결정, 엑셀 수식과 같음). cropwater 파이썬 `service_outlook`은 마지막 참고일까지 봤지만, 서비스에 보이는 값(엑셀)을 따른다. 예상일이 바뀌면 권장 관수량도 따라 바뀐다(참고일에만 닿으면 둘 다 빈 칸).
- **예상일은 "몇 번째 날"로 둔다:** 0 = 지금 필요(출발일에 이미 RAW 이상), 1~3 = 주 지표 몇 번째 날, 빈 칸 = 3일 안에 없음. 기간(`horizon_days`)을 7일·14일로 늘려도 표가 그대로다.
- **출발 상태:** 출발 날짜가 관측 물수지 날이면(아침 회차, 전날 관측 있음) 과습까지 판정하고, 예보로 먼저 진행한 날(저녁 회차의 그날, 관측이 늦은 날)이면 과습은 판정하지 않는다. 휴면기 판정에는 출발 날짜의 Kc를 쓴다.

## 확인
- 예보 대조 테스트(cropwater 운영 경로) 4개 회차의 예상일이 그대로다(그 입력에서는 참고일에만 닿는 경우가 없었음). 참고일에만 닿는 경우는 따로 테스트했다.
