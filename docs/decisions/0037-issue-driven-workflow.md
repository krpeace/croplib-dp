# 결정 0037: 이슈 기반 작업 흐름을 CropMon과 같게 — 계획 댓글 · 120분 기다림 · 다음 이슈 이어 가기

- 날짜: 2026-11-19
- 상태: 채택
- 관련: CropMon 결정 0045(이슈 기반 작업 흐름), 이 저장소 결정 0035(병합 위임)

## 배경

이 저장소는 11/12부터 `지시` 라벨 이슈로 일을 넘겼지만(결정 0035), 작업창이 계획을 어디에 올리고 언제까지 기다리는지, 병합 뒤 무엇을 하는지는 정해져 있지 않았다. CropMon 저장소는 11/18~19에 이 흐름을 다듬었다(댓글 첫머리 표시, 승인 120분 기다림, 병합 뒤 다음 이슈를 스스로 찾기, 검토 채팅 규칙을 `docs/WORKFLOW.md`에, 새 채팅으로 넘기는 숫자 기준). 사용자는 두 저장소 모두 같은 작업 규칙을 따르기를 원한다(11/19).

## 결정

1. 작업창 단계는 `CLAUDE.md` "이슈 작업 흐름" 1~11에 둔다. CropMon과 같은 단계이고, 라벨 이름은 이 저장소에서 쓰던 `지시`를 그대로 쓴다.
2. 검토 채팅 쪽 규칙(맡는 일 · 이슈 쓰는 법 · 도구 · 예약 확인 · 넘기기)은 `docs/WORKFLOW.md`에 둔다. 넘기기 기준은 CropMon과 같다(병합 PR 5개 · 예약 확인 8번 · 12시간 · 이정표 끝 · 다시 찾기).
3. CropMon의 순서표 #144에 해당하는 것으로 이 저장소에도 **순서표 이슈**(제목 `[순서표]`)를 둔다.
4. 병합 조건은 결정 0035 그대로다. 조사(코드 변경 없음) 이슈는 `[검토 채팅] 확인함`으로 끝낸다.
5. "파일 3개 이상이면 계획 먼저"는 "파일을 바꾸기 전에는 늘 계획 먼저"로 넓힌다(계획은 이슈 댓글).
