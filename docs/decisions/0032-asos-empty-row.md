# 0032. 어제 ASOS가 빈 줄로 올 때 (A 지연일 대체 · B 필요한 발표 재시도 · C 빈 줄 = 아직 없음) (#100)

날짜: 2026-11-11 (사용자 승인: A+B+C 한 PR, A 결과는 기존 백업 구분)

## 사고 (2026-11-11 17시 회차)
기상청 ASOS 일자료 API가 **11/10 행을 날짜만 있고 값이 전부 빈 줄로** 돌려줬다(97곳 전부). 같은 날 09:20(적산온도 수집)에는 11/10 값이 있었는데 15:39, 17:15, 18:07, 21:59에는 빈 줄이었다. 어제 관측 ETo가 없으면 마지막 관측일이 11/9가 되어 11/10이 "지연일"이 되고, 그날의 아침(02시) 발표 D+0(17시 회차 기준 39시간 전)이 24시간 창 밖이라 없어서 대표 10곳이 `2026-11-10을 진행할 예보가 없습니다`로 전부 실패했다(대표 밖 87곳은 계산 조건이 없어 이 경로를 안 탐). ReadTimeout은 원인이 아니었다(요약에 마지막 실패 한 줄만 찍혀 그렇게 보였음).

## 결정
1. **A. 지연일 대체**: 지연일의 아침 D+0 예보(또는 그날을 대상으로 한 02시까지의 발표)를 구할 수 없으면 실패하지 않고 **채운 줄로 어제부터 출발**한다. 물수지(`observed_water_balance`)는 끝에 더한 날에 예보도 없으면 **앞 7일 ETo 평균**을 쓴다(강수 0, `eto_src = '없음'`, `filled = true`). 결과는 **기존 `백업: 직전 발표`**로 남기고(결과 값 목록 변경 없음, CropMon 계약 변경 없음), 요약 경고에 `지연일(MM/DD) 예보를 구할 수 없어 채운 값으로 전망을 출발함 — 백업`을 적는다. `src_run_at`은 직전 발표를 실제로 쓴 경우에만 남긴다. 저녁 발표가 오늘 아침 발표를 못 받는 경우는 전과 같이 실패한다(이번 범위 밖).
2. **B. 필요한 앞선 발표 재시도**: 앞선 발표는 지금까지 한 번만 요청했다. **필요한 발표만**(02시 회차 3시간 전·24시간 전, 17시 회차 3시간 전·15시간 전; 대표·대표 밖 모두) 시간 초과 등으로 못 받으면 **30초·90초 뒤 두 번 더** 받는다(`NEEDED_ISSUE_RETRY_S`, ASOS와 같은 방식). 필요하지 않은 앞선 발표는 전과 같이 한 번만 받아 호출 수·회차 시간을 늘리지 않는다. (11/9 안동·11/11 02시 수원 유형: 02시 회차에서 어제 02:00 발표 한 개를 못 받음 — 재시도로 막고, 끝내 못 받아도 A로 실패하지 않는다.)
3. **C. 빈 줄 = 아직 없음**: 일자료 행에서 기온(`maxTa`·`minTa`·`avgTa`)·평균습도·평균풍속이 **모두 비어 있으면** 그 행은 행이 없는 날로 본다(`core/daily_weather.is_empty_row`). **끝의 빈 줄은 결과에서 빠지고**(`weather_daily`·`soil_water_daily`에 강수 0.0·평균 ETo 가짜 줄이 안 써지고 감시가 "어제 관측 없음"으로 센다), 가운데의 빈 줄은 빠진 날로 처리된다(강수 `null`, ETo는 앞 7일 평균·`filled`). 비 안 온 날은 강수 칸만 비므로 기온이 있으면 정상 행이다. 대표 10곳과 대표 밖 87곳 모두 같은 함수를 쓴다.
4. **D(5분 재실행 안 하기)는 별도 이슈, E(Storage에서 옛 발표 읽기)는 하지 않는다**(사용자 결정).

## 화면 영향 (C 이후)
어제 줄이 안 써지면 CropMon은 `soil_water_latest`(지점·토성별 최신 1줄)로 읽으므로 **11/9 줄이 최신으로 보인다.** 그 줄은 관측 확정값이라 값 자체는 정상이다(화면에 표시되는 기준 날짜 문구는 CropMon 쪽 확인 필요). 감시는 18시 뒤 "어제 ASOS 관측 없음(97곳)" 경고로 알린다.

## 한계
- 이미 DB에 올라간 11/10 임시 줄(강수 0·평균 ETo·`filled`)은 ASOS 값이 다시 올 때 덮어써진다(C는 앞으로 안 쓰게 할 뿐 지우지 않음).
- A의 채운 줄은 강수를 0으로 두므로 지연일에 실제로 비가 왔다면 Dr이 높게 나온다. 휴면기엔 Kc 0이라 ETo 무영향이고 강수만 영향을 준다.
- 기상청이 값을 거둬들이는 원인은 알 수 없다.
