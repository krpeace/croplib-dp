# 0016. 기상청 ASOS 지점 목록 현행화 자료 (읽기 전용)

날짜: 2026-10-28 (이슈 #27, CropMon#38)

## 배경
- 화면 시안의 지점은 96곳인데 기상청 기준 ASOS 지점은 105곳이다. 빠진 지점이 있다.
- DB 지점 사전(`stations`)은 10곳이고, 같은 내용이 CropMon `src/infra/stations.ts`에 있다.
- DB 구조와 사전 자료의 주인은 CropMon이다. 이 저장소는 **읽고 파일만 만든다**. 마이그레이션·화면 반영은 CropMon#38이 한다.

## 어디서 받나
- 기상청 API허브 **지점정보 조회** `https://apihub.kma.go.kr/api/typ01/url/stn_inf.php?inf=SFC&stn=&tm=<기준시각>&help=1&authKey=<키>`
  - `inf=SFC`는 지상(ASOS) 지점. `tm`을 주면 그때 운영 중이던 지점이 나온다.
  - 키는 환경변수 `KMA_HUB`(GitHub Secrets 이름과 같음). 코드·로그·커밋에 쓰지 않고, 오류 문구에는 `authKey=***`로 감춘다.
- 응답은 글 표다. `#` 줄은 설명이고, `STN_ID LON LAT ...` 열 이름 줄을 찾아 열 이름으로 읽는다(열 순서가 바뀌어도 됨). UTF-8이 아니면 EUC-KR로 읽는다.

## 열을 어떻게 채우나 (`stations_kma_YYYYMMDD.csv`, UTF-8, 지점번호 순)
| 열 | 출처 |
|---|---|
| `stn_id`, `name_ko`, `lat`, `lon` | `STN_ID`, `STN_KO`, `LAT`, `LON` |
| `elev_m` | `HT` (노장 해발고도) |
| `wind_height_m` | `HT_WD` (풍향·풍속계 지상 높이) |
| `sido` | `LAW_ID`(법정동코드) 앞 2자리 → 시·도 약칭. 강원(42·51), 전북(45·52)은 특별자치도 전후 번호를 모두 받는다. 법정동코드가 없으면 좌표 → 행정구역(OpenStreetMap Nominatim, 키 없음)으로 찾고 `source_note`에 적는다 |
| `measures_sunlight` | 지점정보에는 일사 관측 여부가 없다. CropMon 지점 사전(`stations.ts`)에 적힌 10곳만 채우고 나머지는 **빈 칸**(추측하지 않음) |
| `is_active` | 아래 "폐지·휴지 지점" |
| `source_note` | 출처와 채운 방법 |

- `-999` 같은 결측 표시는 빈 칸으로 쓴다.
- 시·도는 약칭(서울·부산·…·경기·강원·충북·충남·전북·전남·경북·경남·제주) 17개만 쓴다.

## 폐지·휴지 지점
- 지금 운영 중 = 오늘(한국 날짜) 기준 조회에 나온 지점 → `is_active=true`.
- 2000년부터 해마다 **1월 1일 기준**으로 다시 조회해서, 지난 목록에는 있고 지금은 없는 지점 → `is_active=false`. 이름·좌표는 마지막으로 보인 해의 값을 쓰고, 그 날짜를 `source_note`에 적는다.
- 1월 1일 사이에 생겼다가 없어진 지점은 놓칠 수 있다. 시안·DB와 비교하는 데는 충분하다고 보았다.

## 어떻게 비교하나 (`stations_diff.md`)
- 기준 목록: 이슈 #27의 시안 96곳(`core/stations.DRAFT_96`)과 DB 사전 10곳(`core/stations.DB_STATIONS`, `stations.ts`를 옮겨 적음).
- (가) 기상청 현행인데 시안에도 DB에도 없는 지점
- (나) 시안·DB에 있는데 기상청 현행 목록에 없는 지점. 지난 목록에서 찾으면 "폐지·휴지(날짜)", 못 찾으면 "지점정보에 없음(번호 확인 필요)"
- (다) 이름·번호가 다른 지점. 시안은 번호만 있어 이름이 있는 DB 사전 10곳만 비교한다(같은 번호에 다른 이름, 또는 같은 이름이 다른 번호).

## 실패를 어떻게 알리나
- 응답이 비었거나, 열 이름 줄·필요한 열(`STN_ID`, `LON`, `LAT`, `STN_KO`)이 없거나, 번호·좌표가 숫자가 아니거나, 같은 번호가 두 번 나오거나, 시·도를 정하지 못하면 **파일을 쓰지 않고** 종료 코드 1로 끝낸다. 한 해라도 받지 못해도 같다.
- 쓰기 전에 열 이름·순서, 번호 중복, 시·도 약칭, 좌표 범위를 다시 검사한다.

## 하지 않는 것
- DB 쓰기, 마이그레이션, CropMon·cropwater 수정, 예약 실행. 지점이 자주 바뀌지 않아 필요할 때 손으로 한 번 돌린다.
- 지점별 물 계산 확대(별도 결정).
